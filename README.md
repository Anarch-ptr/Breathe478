# Breathe478

Breathe478 is a simple Android breathing exercise app based on the 4-7-8 breathing method.

## Features

- Guided 4-7-8 breathing session
- Rounds selection
- Countdown for inhale, hold, and exhale stages
- Remaining time display
- Pause and resume
- Haptic feedback
- Eyes-closed mode
- Simple breathing animation

## Tech Stack

- Kotlin
- Jetpack Compose
- Android Studio

## How to Run

1. Clone this repository.
2. Open the project in Android Studio.
3. Sync Gradle.
4. Run the app on an Android emulator or physical device.

## Project Purpose

This project was created as a simple mobile app practice project to explore Android development, Jetpack Compose UI, timer logic, and user interaction design.
